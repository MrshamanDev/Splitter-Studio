# Contributing

Thanks for helping improve Splitter Studio! The issue tracker is open to everyone.

## Reporting a bug

Open a [bug report](../../issues/new?template=bug_report.md) and include:

1. Splitter Studio version (bottom-right of the window, e.g. v1.0.0)
2. Windows version (Win+R → `winver`)
3. What you did and what you expected vs. what happened
4. The image format/size if relevant (PNG 941×1672, TIFF 16-bit, …) — **never attach
   the image itself unless it is yours and you are comfortable sharing it**
5. Relevant lines from the log at `%LOCALAPPDATA%\SplitterStudio\logs`
   (logs never contain image contents)

## Requesting a feature

Open a [feature request](../../issues/new?template=feature_request.md) and describe
the **problem** you are trying to solve, not only the solution you imagine. Real
print workflows described in detail are the most useful.

## Scope notes

Splitter Studio is built around hard guarantees — exact physical dimensions, original
image fidelity, honest print status. Proposals that conflict with these (for example
"silently upscale my image" or "auto-fit tiles to the page") will be declined, but
framing that preserves the guarantee is always welcome.

## Code contributions

The source tree is not published in this repository yet. If/when it opens, a full
contributor guide (build, test, style) will appear here. Until then, detailed issue
reports are the most valuable contribution you can make.
